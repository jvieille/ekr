# Public Canonical-Impact Decision Records

**Status: public governance index**

This directory records accepted decisions that materially affect the public meaning or status of EKR.

It does not contain ordinary repository housekeeping decisions, routine issue triage or every Draft Guidance edit. It is used when a decision has canonical impact or materially affects a public canonical proposition.

## Current records

No canonical-impact decision record has been published in this directory yet.

## Record contents

A decision record should identify, as applicable:

1. **Decision ID and date**
2. **Proposal or question**
3. **Public status before the decision**
4. **Decision**
5. **Public rationale**
6. **Affected public/canonical artefact**
7. **Effective version or release**
8. **Related Discussion, Issue or pull request**

Confidential or non-public review material, protected implementation detail, and information that cannot lawfully be disclosed are not required to be published in a public decision record.

See the [Public EKR Canonicality Policy](../CANONICAL-POLICY.md).
