# Proposals

**Status: Proposal intake/index area**

A Proposal is a structured suggestion, alternative, pattern or change request submitted for evaluation. A proposal is **not** an accepted EKR position merely because it appears in this repository.

Currently, structured proposals should normally enter through the [Architectural Proposal Issue form](https://github.com/jvieille/ekr/issues/new/choose). This directory may also index or hold proposal artefacts when a durable repository document is useful.

Status: Proposal / candidate Guidance material / non-canonical.

Proposal review may result in:

- further Discussion;
- a request for evidence or clarification;
- no change;
- a Draft Guidance change;
- separate claim review for a materially new public proposition; or
- canonical-impact escalation under the [Canonicality Policy](../governance/CANONICAL-POLICY.md).

Do not place confidential, protected or unpublished implementation material here.
