# Working Definition Companions

This directory contains contributor-authored reading aids for the canonical **Enterprise Knowledge Representation — Working Definition V0.1**.

These files are explanatory repository material. They are **not canonical EKR definitions**, do not amend the Working Definition, and do not acquire canonical authority through publication or merge.

The canonical public definition remains the English V0.1 archived at its DOI:

**Jean Vieille. _Enterprise Knowledge Representation — Working Definition V0.1_. Version 0.1, 14 August 2026.**  
https://doi.org/10.5281/zenodo.21914714

A companion should:

- identify its author;
- state clearly that it is non-canonical;
- identify the canonical Working Definition on which it is based;
- distinguish plain-language reader aids from canonical wording;
- avoid introducing a competing definition or silently changing EKR boundaries.
